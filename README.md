# ML-IoT-based-Flood-Safe-Waterfalls-Alert-System

This project presents a smart flood alert system tailored for waterfall-prone areas using Machine Learning and IoT. It monitors real-time weather data and water flow using sensors and predicts flood risk with high accuracy. Alerts are issued via LEDs, buzzers, and a web interface. LoRa technology ensures long-range communication. The system enhances public safety and is scalable for future upgrades like SMS alerts or mobile app integration.
